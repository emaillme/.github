### How it works

1. **You write the email.** Send it from the inbox you already use, and ask the way you'd ask a person.
2. **It does the reading.** The whole thread, the PDF, the photo of the form. If the answer needs looking up, it looks it up instead of guessing.
3. **You get a reply.** A normal email in the same thread. Ask a follow-up and it picks up where it left off. No dashboard, no tab to keep open.

### For work: emaillme Pro

Lookup-and-reply emails pull you away from the work only you can do. Pro gives your agent its own address. It drafts the answers to those emails from your docs and connections, and you choose how much it sends on its own. [See Pro](https://emaillme.com/pro)

### Open source from emaillme

**[botmail](https://github.com/emaillme/botmail)** gives your AI agent its own email address on Amazon SES and S3, plus a command-line mail client it can use to list, read, wait for, send, and reply to mail. It runs in your own AWS account and comes with a CloudFormation template that sets it up.

```bash
pip install botmail-cli
```

If you'd rather not run mail infrastructure at all, [emaillme](https://emaillme.com) does the hosting for you.
